## Cómo subirlo a tu repositorio

1. Descomprime el ZIP.
2. En tu repositorio de GitHub, elimina los archivos anteriores si quieres reemplazar todo.
3. Sube estos 4 archivos nuevos.
4. Espera 1 o 2 minutos.
5. Abre tu página y presiona **Ctrl + F5** para forzar actualización.

## Importante

En `index.html` y `styles.css` se agregó `?v=2` para ayudar a que el navegador no use caché viejo:

- `styles.css?v=2`
- `app.js?v=2`

Si luego haces otros cambios, puedes subir a `v=3`, `v=4`, etc.
